## CISO Radar

An information and analytical cyber threat monitoring service designed for information security and IT managers.

The service automates the complete workflow, from collecting information from public sources to preparing and publishing analytical materials.

### Implemented features

- automated collection of information from 93 industry sources;
- filtering and initial processing of collected materials;
- analysis of news relevance for security and IT management;
- generation of structured analytical publications;
- preparation of Russian and English versions;
- automated weekly digest generation;
- generation of visual publication cards;
- automated Telegram publishing;
- administrative web interface for reviewing and managing drafts;
- logging of collection, processing and publishing workflows;
- containerised deployment on a remote server.

### My contribution

I independently developed the project, from architecture design and data-processing logic to server configuration and production deployment.

My responsibilities included:

- application architecture;
- information collection and processing pipeline;
- integration with language models;
- administrative web interface;
- weekly digest generation;
- Telegram integration;
- data storage and processing;
- Docker environment;
- application deployment and maintenance.

## CovePilot

A local-first macOS application that places a compact interactive island next to the physical MacBook notch.

The application provides useful local context and quick access to tools without overloading the macOS menu bar.

### Implemented features

- compact interface around the MacBook notch;
- Agents, Music, Widgets and System sections;
- Russian and English localisation;
- timers and local widgets;
- music controls;
- system context;
- visual reactions to user actions;
- multiple visual themes;
- custom theme import and export;
- local-first architecture;
- DMG packaging and distribution.

### My contribution

I participated in product design, interface and feature development, testing, documentation and preparation of the public technical preview.

### Technologies

`Swift` `SwiftUI` `macOS` `Xcode` `Git` `GitHub Actions` `ZIPFoundation`
